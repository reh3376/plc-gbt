# Data Directory

This directory contains various data files used by the PLC-GBT project.

## Structure

- `ingestion_sessions/` - JSON files from memory system ingestion sessions
  - Contains timestamped session data from the intelligent ingestion process
  - Files follow the pattern: `ingestion_session_intelligent_{timestamp}.json`

## Note

These files are typically generated automatically by the memory ingestion system and should not be manually edited.
